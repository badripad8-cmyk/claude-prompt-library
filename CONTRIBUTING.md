# Contributing to Claude Prompt Library

Thank you for wanting to make this better! Here’s everything you need.

-----

## How to Add a Prompt

1. **Fork** this repository (click the Fork button top-right on GitHub)
1. **Clone** your fork to your computer (or edit directly on GitHub)
1. **Find** the right category file or section in README.md
1. **Add your prompt** using this format:

```markdown
### [NUMBER]. [Title of Your Prompt]
```

[YOUR PROMPT TEXT HERE]

Use [BRACKETS] for anything the user should customize.

```
5. **Test it** — paste it into Claude and make sure it actually works well
6. **Submit a Pull Request** with a short description of what the prompt does

---

## Prompt Quality Checklist

Before submitting, make sure your prompt:

- [ ] Has a clear, descriptive title
- [ ] Uses `[BRACKETED PLACEHOLDERS]` for user-customizable parts
- [ ] Has been tested with Claude
- [ ] Is genuinely useful (not just clever)
- [ ] Fits naturally into an existing category
- [ ] Is not a duplicate of an existing prompt

---

## Adding a New Category

If your prompt doesn't fit any existing category and you have 5+ prompts for a new one:

1. Open an Issue first to discuss it
2. Use the same format as existing categories
3. Add it to the Table of Contents in README.md

---
```
