## 📖 How to Use This Library

1. **Find** a prompt category that fits your need
1. **Copy** the prompt exactly as written
1. **Paste** it into [claude.ai](https://claude.ai)
1. **Customize** the parts in `[brackets]` with your own details
1. **Iterate** — ask Claude to refine, expand, or change its response

> 💡 **Pro Tip:** The more context you give Claude, the better the output. Don’t be afraid to add details about your situation, audience, or goals.

## ✍️ Writing & Content

### 1. The Deep Blog Post Generator

```
Write a comprehensive, engaging blog post about [TOPIC] for [TARGET AUDIENCE].

Structure it with:
- A hook opening that starts with a surprising fact or question
- Clear H2 and H3 headings
- Practical examples or stories in each section
- A strong conclusion with a call to action

Tone: [conversational / professional / inspiring]
Length: Approximately [800 / 1500 / 2500] words
```

-----

### 2. The Cold Email That Gets Replies

```
Write a cold outreach email from [YOUR ROLE] to [RECIPIENT ROLE] at [TYPE OF COMPANY].

Goal: [What you want — a meeting, collaboration, feedback, etc.]

Rules:
- Subject line under 8 words
- Opening line references something specific about them
- Body is under 100 words
- One clear CTA
- No fluff, no "I hope this email finds you well"
```

-----

### 3. The Story Expander

```
I have a story idea: [DESCRIBE YOUR IDEA IN 1-2 SENTENCES].

Help me develop it by:
1. Suggesting 3 different directions this story could go
2. Creating a compelling main character with flaws
3. Building tension through a central conflict
4. Writing the opening 3 paragraphs in vivid detail

Genre: [thriller / romance / sci-fi / literary fiction / etc.]
```

-----

### 4. Rewrite Anything Instantly

```
Rewrite the following text with these goals:
- Make it [shorter / clearer / more persuasive / more formal / more casual]
- Audience: [who will read this]
- Keep all key information intact

Original text:
[PASTE YOUR TEXT HERE]
```

-----

### 5. The LinkedIn Post Formula

```
Write a LinkedIn post about [TOPIC OR PERSONAL EXPERIENCE].

Make it:
- Start with one powerful sentence (no "I'm excited to announce")
- Use short paragraphs (1-2 lines max)
- Include 1 insight or lesson
- End with a question to spark comments
- 150-250 words total

My perspective/angle: [YOUR UNIQUE TAKE OR EXPERIENCE]
```

-----

### 6. Newsletter Writer

```
Write a weekly newsletter section for [YOUR NEWSLETTER NAME] about [THIS WEEK'S TOPIC].

My audience: [DESCRIBE YOUR SUBSCRIBERS]
Tone: [warm and personal / witty / educational / etc.]
Include: A main insight, one example, and a "this week's recommendation" section.
Word count: ~400 words
```

-----

### 7. Speech or Presentation Opener

```
Write a powerful 60-second opening for a [presentation / speech / pitch] about [TOPIC].

Context:
- Audience: [WHO THEY ARE]
- Setting: [conference / classroom / boardroom / etc.]
- Goal: [inform / persuade / inspire / entertain]

Start with a story, a bold claim, or a provocative question — not "Today I'll be talking about..."
```

-----

### 8. The Apology or Difficult Message

```
Help me write a [email / message / letter] that:
- Addresses: [THE SITUATION]
- My relationship with this person: [colleague / friend / client / etc.]
- What I want to achieve: [repair trust / clarify a misunderstanding / apologize / etc.]
- Tone: sincere, direct, no excuses

Draft it in a way that's human and not corporate-sounding.
```

-----

### 9. Product Description Writer

```
Write 3 versions of a product description for [PRODUCT NAME].

Product details: [KEY FEATURES AND BENEFITS]
Target customer: [WHO BUYS THIS]

Version 1: Short (50 words) — for social media
Version 2: Medium (150 words) — for a website
Version 3: Long (300 words) — for Amazon or a detailed catalog

Focus on benefits over features.
```

### 10. The Creative Title Generator

```
Generate 20 title options for [blog post / book / video / podcast episode / course] about [TOPIC].

Mix styles:
- 5 curiosity-driven titles (make them wonder)
- 5 benefit-driven titles (what they'll gain)
- 5 bold/provocative titles
- 5 simple and direct titles

I'll pick my favorites.

## 🔍 Research & Analysis

### 11. The Expert Breakdown

```
Explain [COMPLEX TOPIC] as if you're a world-class expert talking to a smart but non-specialist audience.

Structure:
1. What it is (plain English)
2. Why it matters
3. How it works (with an analogy)
4. Common misconceptions
5. What most people miss about it
```

-----

### 12. The Devil’s Advocate

```
I believe [YOUR POSITION OR BELIEF].

Play devil's advocate. Give me the strongest possible case AGAINST my position. Be rigorous, not dismissive. I want to genuinely stress-test my thinking.

Then tell me: what's the strongest version of my original position in response to your critique?
```

-----

### 13. The Research Synthesizer

```
I'm researching [TOPIC]. Here's what I know so far:

[PASTE YOUR NOTES OR SUMMARY]

Help me:
1. Identify gaps in my understanding
2. Suggest 5 key questions I should be asking
3. Highlight any assumptions I might be making
4. Point me toward what I should explore next
```

-----

### 14. The Bias Checker

```
Here is an argument or piece of writing I want to analyze:

[PASTE TEXT]

Identify:
- Any logical fallacies present
- Hidden assumptions
- Emotional language used to persuade
- What's missing from the argument
- An overall fairness rating (1-10) with explanation
```

-----

### 15. Compare Anything

```
Compare [OPTION A] vs [OPTION B] for someone who [CONTEXT ABOUT THE PERSON/USE CASE].

Use a structured format:
- Key differences (table format)
- When to choose A
- When to choose B
- What most comparisons get wrong about these two
- My recommendation based on: [YOUR SPECIFIC SITUATION]
```

-----

### 16. The News Explainer

```
Explain [CURRENT EVENT OR NEWS TOPIC] to me as if I know nothing about it.

Cover:
1. What happened (facts only)
2. Why this is significant
3. Who the key players are
4. Different perspectives on it
5. What might happen next

Stay balanced and don't editorialize.
```

-----

### 17. The “So What?” Analyzer

```
Here's a statistic or finding I came across:

"[PASTE THE STAT OR CLAIM]"

Help me understand:
- What this actually means in plain terms
- What context is missing
- Whether this is likely cherry-picked or misleading
- What the "so what" is — why should I care?
```

-----

### 18. Book/Article Summarizer

```
Summarize the key ideas from [BOOK/ARTICLE TITLE] by [AUTHOR].

Format:
- Core argument (2-3 sentences)
- 5 most important insights
- 1 idea that challenged conventional wisdom
- 3 actionable takeaways
- Who should read this and why

If you're uncertain about any details, say so.
```

## 💡 Brainstorming & Ideas

### 19. The 100 Ideas Sprint

```
Generate 100 ideas for [TOPIC / PROBLEM / GOAL].

Don't filter. Don't explain. Just list them fast. Number each one.

I know most won't be good — that's the point. I'm looking for the 3-5 surprising ones hiding in the list.
```

-----

### 20. The Problem Reframer

```
I'm stuck on this problem: [DESCRIBE YOUR PROBLEM]

Help me see it differently by:
1. Reframing it as an opportunity
2. Asking what would need to be true for this to be easy
3. Suggesting how a 10-year-old might approach it
4. Suggesting how a Fortune 500 CEO might approach it
5. Proposing the most unconventional solution you can think of
```

-----

### 21. The “What If” Expander

```
Take this idea: [YOUR IDEA]

Run 10 "What if" scenarios to push it further:
What if it was 10x bigger?
What if it was free?
What if the opposite were true?
What if it happened overnight?
What if it was for children instead?
...and so on.

Help me see the full possibility space.
```

-----

### 22. The Product Idea Validator

```
I have a business idea: [DESCRIBE IT IN 2-3 SENTENCES]

Help me quickly validate or stress-test it:
1. Who is the ideal customer? (be specific)
2. What problem does it solve — and how painful is that problem?
3. Who already does this? (competition)
4. What's the riskiest assumption in this idea?
5. What would I need to prove in 30 days to know if it works?
```

-----

### 23. The Creative Mashup

```
Combine these two unrelated things into a single original idea:

Thing 1: [FIRST CONCEPT / INDUSTRY / OBJECT]
Thing 2: [SECOND CONCEPT / INDUSTRY / OBJECT]

Give me 5 creative ways to merge them — could be a product, a story, a business, an art project, or anything interesting.
```

-----

### 24. The Future Scenarios Builder

```
Project 3 future scenarios for [INDUSTRY / TECHNOLOGY / TREND] over the next 10 years:

1. The Optimistic Scenario — things go well
2. The Pessimistic Scenario — things go wrong
3. The Weird/Unexpected Scenario — something nobody predicted

For each: describe what the world looks like, who wins, who loses, and what opportunities emerge.
```

### 25. The Name Generator

```
Generate name ideas for my [business / product / app / podcast / newsletter] that:

What it does: [DESCRIBE IN ONE SENTENCE]
Audience: [WHO IT'S FOR]
Feeling I want the name to evoke: [MODERN / WARM / BOLD / PLAYFUL / TRUSTWORTHY / etc.]

Give me:
- 10 single-word names
- 10 two-word combinations
- 5 made-up/coined words
- 5 metaphor-based names
```

### 26. The Constraint Creativity Prompt

```
I need to [ACHIEVE A GOAL] but I have these constraints:
- [CONSTRAINT 1 — e.g. no budget]
- [CONSTRAINT 2 — e.g. only 1 week]
- [CONSTRAINT 3 — e.g. just me, no team]

Generate 10 creative solutions that work *within* these constraints, not around them. Constraints are the creative brief.
```

## 📈 Business & Productivity

### 27. The Strategy Memo

```
Write a one-page strategy memo for [PROJECT OR INITIATIVE].

Include:
- The problem we're solving
- Our proposed approach
- Key risks and how we'll mitigate them
- Success metrics
- Timeline overview

Audience: [WHO WILL READ THIS — execs / team / investors]
Tone: Clear, direct, no jargon
```

End with clear next steps format.

### 35. The Competitive Analysis

```
Help me build a competitive analysis for [YOUR PRODUCT/SERVICE] vs. [COMPETITOR 1], [COMPETITOR 2], [COMPETITOR 3].

For each competitor, assess:
- Their core value proposition
- Their key strengths
- Their visible weaknesses
- Who their ideal customer seems to be

Then: where is the gap in the market that none of them are filling well?
```

## 🎓 Learning & Education

### 37. The Feynman Teacher

```
Explain [CONCEPT] using the Feynman technique:

1. Explain it in the simplest possible language — as if to a 12-year-old
2. Use one powerful analogy
3. Show a real-world example
4. Identify the one part most people find confusing and explain that specifically
5. Test my understanding: ask me 3 questions about it at the end
```

Include:
- Key concepts and definitions (top 15)

- A 1-week study schedule
- 3 practice questions with detailed answers

### 53. The Decision Framework

```
I'm trying to decide between:

Option A: [DESCRIBE]
Option B: [DESCRIBE]
Option C: [DESCRIBE — or remove if only two]

Context: [YOUR SITUATION, CONSTRAINTS, VALUES]

Don't just list pros and cons. Help me understand:
1. What I'm actually optimizing for
2. What I'd regret more in 10 years

## 🔮 Advanced Techniques

### 61. The Role Assignment Prompt

```
You are a [SPECIFIC EXPERT ROLE — e.g. "seasoned venture capitalist who has funded 50+ startups" or "a no-nonsense editor at The New Yorker"].

With that expertise and perspective, [YOUR REQUEST].

Be opinionated. Don't hedge. Tell me what you actually think, not what's safe to say.
```

-----

### 62. The Chain-of-Thought Activator

```
[YOUR QUESTION OR PROBLEM]

Before answering, think through this step by step. Show your reasoning process explicitly. I want to see how you arrive at the answer, not just the answer itself.
```

-----

### 63. The Prompt Improver

```
Here is a prompt I've been using:

[PASTE YOUR CURRENT PROMPT]

Make it better. Tell me:
1. What's weak or vague about it
2. What context is missing
3. Rewrite it as an improved version
4. Explain what you changed and why
```

-----

### 64. The Constraint Mode

```
Answer this question: [YOUR QUESTION]

Constraints:
- Maximum 5 sentences
- No jargon or technical terms
- Must include one unexpected insight
- Must end with a question that challenges my assumptions
```

-----

### 65. The Multi-Perspective Analyst

```
Analyze [TOPIC / SITUATION / DECISION] from these 4 perspectives:

1. 🧠 The Rationalist — pure logic and data
2. ❤️ The Humanist — human impact and emotion
3. 💰 The Pragmatist — what's realistic given resources
4. 🔭 The Visionary — long-term, big picture

After all four: synthesize — what does the full picture suggest?
```

-----

### 66. The Stress-Test Prompt

```
Here is my plan / idea / decision:

[DESCRIBE IT IN DETAIL]

Stress-test it. Be the harshest critic imaginable. Find every flaw, assumption, risk, and blind spot. Don't hold back.

Then — having torn it apart — tell me: what's the version of this that actually works?
```
